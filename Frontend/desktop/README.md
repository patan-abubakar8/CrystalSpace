# Frontend Desktop Client (Flutter Desktop)

This directory hosts the cross-platform desktop application (Windows, macOS, Linux) built with Flutter Desktop.

### Synergy with `Frontend/mobile`
- **Engine**: Flutter (Dart)
- **Code Sharing**: High synergy with `Frontend/mobile` (shared data models, DTOs, API clients, and business logic state management).
- **Target OS**: Windows, macOS, Linux.
- **Networking & Auth**: Dio / Http with JWT Bearer tokens and secure storage.
